# Code of Conduct

## Our standard

Participation in the MusicVault project is expected to be respectful, constructive, and considerate. Examples of unacceptable behavior include harassment, personal attacks, discriminatory language, publishing another person's private information, and deliberately disrupting project discussions.

## Project spaces

This policy applies to issues, pull requests, discussions, review comments, and other spaces where contributors represent the project.

## Enforcement

Project maintainers may edit or remove contributions that violate this policy and may restrict participation for repeated or serious violations. Report concerns privately using the reporting route in [SECURITY.md](SECURITY.md), clearly marking conduct reports as such.

This is a lightweight project policy. It does not replace GitHub's Terms of Service or Community Guidelines.
