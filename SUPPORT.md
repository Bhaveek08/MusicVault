# Support

For normal usage questions, first check the installation and limitations documented in [README.md](README.md).

For reproducible defects, open a GitHub issue using the bug report template. Include the MusicVault version, OS version and architecture, reproduction steps, and a redacted error message. Do not attach unredacted logs, credentials, private media URLs, or personal data.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

MusicVault is a small independent project; response times and compatibility with future platform changes are not guaranteed.
